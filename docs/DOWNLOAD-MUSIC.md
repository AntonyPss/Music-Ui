## Installation Steps

1. **Download the audio files**
   - Use a YouTube to MP3 converter to download the tracks
   - Or download directly from NCS if available

2. **Convert to .ogg format**
   - Use an online converter like https://convertio.co/mp3-ogg/
   - Or use Audacity: File > Export > Export as OGG
   - Ensure the bitrate is reasonable (128-192 kbps recommended)

3. **Place files in the correct location**
   - Copy all .ogg files to: `sounds/music/`
   - The folder structure should be:
     ```
     sounds/
       music/
         ncs_back_again.ogg (existing)
         brazilian-phonk.ogg (existing)
         hard-phonk.ogg (existing)
         my_heart.ogg (new)
         on_and_on.ogg (new)
         heroes_tonight.ogg (new)
         invincible.ogg (new)
         levels.ogg (new)
         cloud_9.ogg (new)
         summertime.ogg (new)
     ```

4. **Test in Minecraft**
   - Reload the resource pack
   - Open the Music UI
   - All 10 tracks should be visible and playable

## Cover Art

For the new tracks, you can either:
- Use the existing `textures/covers/cover_1.png` for all
- Create custom cover art and name them `cover_4.png` through `cover_10.png`
- Update `music_list.json` to reference the new cover files
